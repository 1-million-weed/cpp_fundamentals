The compiler interprets the statement as follows; first it checks the condition (first == test) if true, then the codition (sencond ==test2) is evaluated. 
If the condition (second == test2) is not true then the code in the else block is executed. The correct layour for the statement is as follows;


int main() 
{
    if (first == test1) 
    {   
        if (second == test2)
        { 
            value = 5;
        }
        else 
        {
        value = 6;
        }
    }
}

To use the 'non-default' interpretation you can rewirte the statement like this;

int main() 
{
    if (first == test1) 
    {   
        if (second == test2)
        { 
            value = 5;
        }
    }
    else 
    {
        value = 6;
    }

}

Now the compiler interprets the changed statement like this:
First the condition (first == test1) is checked.
If this condition is true, then the inner if (second == test2) is checked.
If it is true, then value = 5
If it is false, then nothing happens.
If the condition (first == test1) is false, the else is executed and value = 6

The flaw in the way the original statement was formulated is that the else is always matched to the closest unmatched if, which may not be your intent.
